## Verified source #2 snapshot (partial)

- Default branch `main` was pinned at [`70c23c80641d7370532af2f619b2842658600842`](https://github.com/ChrisTitusTech/winutil/tree/70c23c80641d7370532af2f619b2842658600842). The latest release observed was `26.11.13`, published 2026-11-13, at [`74607a0613d817eeb5cb35d187b5d7b31e23f386`](https://github.com/ChrisTitusTech/winutil/tree/74607a0613d817eeb5cb35d187b5d7b31e23f386). The inspected End Task tweak block is identical at both revisions. The [`main LICENSE`](https://github.com/ChrisTitusTech/winutil/blob/70c23c80641d7370532af2f619b2842658600842/LICENSE) and [`release LICENSE`](https://github.com/ChrisTitusTech/winutil/blob/74607a0613d817eeb5cb35d187b5d7b31e23f386/LICENSE) are MIT; no upstream code or configuration was copied.
- The project describes a PowerShell/WPF utility with JSON tweak configuration, Pester tests, and a generated `winutil.ps1` entry script. See [`README.md`](https://github.com/ChrisTitusTech/winutil/blob/70c23c80641d7370532af2f619b2842658600842/README.md#L7-L28), [`SPEC.md`](https://github.com/ChrisTitusTech/winutil/blob/70c23c80641d7370532af2f619b2842658600842/SPEC.md#L11-L34), [`Compile.ps1`](https://github.com/ChrisTitusTech/winutil/blob/70c23c80641d7370532af2f619b2842658600842/Compile.ps1#L11-L54), and [`windev.ps1`](https://github.com/ChrisTitusTech/winutil/blob/70c23c80641d7370532af2f619b2842658600842/windev.ps1#L1-L11). The README documents administrator launch for the overall utility.
- [`config/tweaks.json`](https://github.com/ChrisTitusTech/winutil/blob/70c23c80641d7370532af2f619b2842658600842/config/tweaks.json#L920-L935) defines `WPFTweaksEndTaskOnTaskbar`: it writes `HKCU\\Software\\Microsoft\\Windows\\CurrentVersion\\Explorer\\Advanced\\TaskbarDeveloperSettings\\TaskbarEndTask` as `REG_DWORD 1` and sets `OriginalValue` to `<RemoveEntry>`. [`config/preset.json`](https://github.com/ChrisTitusTech/winutil/blob/70c23c80641d7370532af2f619b2842658600842/config/preset.json#L1-L40) includes it in Standard and Advanced, not Minimal.
- The Tweaks tab generates controls from the JSON configuration in [`Initialize-WinUtilTabContent.ps1`](https://github.com/ChrisTitusTech/winutil/blob/70c23c80641d7370532af2f619b2842658600842/functions/private/Initialize-WinUtilTabContent.ps1#L34-L51). The button queues selected tweaks in [`Invoke-WPFtweaksbutton.ps1`](https://github.com/ChrisTitusTech/winutil/blob/70c23c80641d7370532af2f619b2842658600842/functions/public/Invoke-WPFtweaksbutton.ps1#L9-L60); [`Invoke-WinUtilTweaks.ps1`](https://github.com/ChrisTitusTech/winutil/blob/70c23c80641d7370532af2f619b2842658600842/functions/private/Invoke-WinUtilTweaks.ps1#L30-L43) selects `OriginalValue` for undo and dispatches registry entries at [lines 80-90](https://github.com/ChrisTitusTech/winutil/blob/70c23c80641d7370532af2f619b2842658600842/functions/private/Invoke-WinUtilTweaks.ps1#L80-L90).
- [`Set-WinUtilRegistry.ps1`](https://github.com/ChrisTitusTech/winutil/blob/70c23c80641d7370532af2f619b2842658600842/functions/private/Set-WinUtilRegistry.ps1#L30-L63) creates a missing registry key when applying a value and removes the named value for `<RemoveEntry>`. This undo path does not retain a pre-existing raw value or whether the subkey existed, so DebloatX would need to capture and restore both before implementing the behavior.
- [`configs.Tests.ps1`](https://github.com/ChrisTitusTech/winutil/blob/70c23c80641d7370532af2f619b2842658600842/pester/configs.Tests.ps1#L190-L230) checks generic undo metadata, and [`tweaks.Tests.ps1`](https://github.com/ChrisTitusTech/winutil/blob/70c23c80641d7370532af2f619b2842658600842/pester/tweaks.Tests.ps1#L117-L168) covers generic apply/undo dispatch. The inspected files contain no End Task-specific registry integration test. [CI installs Pester and runs the test files](https://github.com/ChrisTitusTech/winutil/blob/70c23c80641d7370532af2f619b2842658600842/.github/workflows/unittests.yaml#L40-L52).
- Microsoft documents the End task taskbar feature in its [Windows 11 22H2 configuration update](https://support.microsoft.com/en-us/servicing/os/configuration-updates/2023/08/september-26-2023-windows-configuration-update), which applies to all editions and was gradually rolled out. The [Windows Developer Blog](https://blogs.windows.com/windowsdeveloper/2023/09/26/new-experiences-designed-to-make-every-developer-more-productive-on-windows-11/) describes enabling it from Developer settings. Microsoft does not document the `TaskbarEndTask` registry value itself; that implementation detail is evidenced by WinUtil.
- This is a partial survey of source #2. Other tweak families, application removal, presets beyond this setting, and broader runtime behavior remain pending. No code or configuration was copied.
